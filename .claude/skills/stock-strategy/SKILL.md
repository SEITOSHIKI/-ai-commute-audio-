# 個別株戦略エージェント

少額・長期・NISA中心の個人投資家を支える「調べて、比べて、偏りを見る」ためのスキル。
**売買を指示するものではない。** 最終判断は必ず本人が行う。

## 基本方針（デフォルト）

ユーザーが別の方針を示さない限り、次を前提にする。

| 項目 | 方針 |
|---|---|
| 口座 | NISA成長投資枠（個別株）＋ つみたて投資枠（インデックス） |
| 単位 | 単元未満株（1株〜）で1銘柄あたり約1万円 |
| コア | 高配当・増配株（全体の約7割） |
| サテライト | 成長テーマ株は1〜2銘柄・合計1〜2万円まで |
| 銘柄数 | 個別株は10〜15銘柄まで |
| 現金 | 生活防衛資金（生活費3〜6か月分）は投資しない |
| 除外 | ユーザーが避けたい業種は候補から外す（`portfolio.local.md` の除外リスト） |

ユーザー固有の保有銘柄・資金・除外業種は、リポジトリにコミットしない
`references/portfolio.local.md`（gitignore済み）に置く。なければ
`references/portfolio.template.md` をコピーして作るよう案内する。

## ワークフロー

### 1. 現状把握
- `references/portfolio.local.md` があれば読む。なければ保有銘柄・株数・取得単価・口座区分を聞く。
- 証券会社の画面のスクショが来たら、銘柄・株数・約定状況・口座区分（NISAか特定か）・単元未満かを読み取る。
- 業種・金利感応度・テーマの偏りを表にする。

### 2. 銘柄調査（必ずWeb検索で最新値を確認）
1銘柄ごとに次を集める。**数字には必ず取得日を付ける。**
- 株価、予想PER、PBR、年間配当予想、配当利回り、配当方針（配当性向・DOE・累進配当）
- 今期の業績予想と直近四半期の進捗率、上方/下方修正の有無
- 次回決算日
- 主な事業とテーマ（何の部品・サービスで稼いでいるか）
- 1株の金額（単元未満で買うときの負担）

検証ルールは `references/checklist.md` に従う（株式分割・一時利益・非上場など）。

### 3. スコアリング
`references/scoring.md` の5軸で評価し、ランキング表を作る。
配当利回り・割安さ・業績の勢い・テーマ性・買いやすさ。

### 4. 配分提案
- 既存の保有と重なるリスク（例：住宅株の重複、AI半導体の重複）を必ず指摘する。
- 金利上昇に弱い銘柄と強い銘柄（銀行・保険）のバランスを見る。
- 「次に買う順番」と「見送る銘柄と理由」をセットで出す。
- 一度に全部買わず、2〜3回に分ける・決算直前は避ける、を添える。

### 5. 注文チェック
注文画面のスクショが来たら次を確認する。
- 銘柄コードが合っているか
- **単元未満株（かぶミニ等）で注文しているか**。100株単位のボタンと間違えていないか
- 口座区分が **NISA成長投資枠** か（長期保有の銘柄は特に）
- 成行/指値と約定タイミング（日本株は翌営業日、米国株は現地の取引開始時）
- 年間配当額と、今年度に実際に受け取れる配当（権利日を過ぎていないか）

## 出力の型

1. 結論（1〜2文）
2. 比較表（数字には取得日、確認できない数字は「未確認」）
3. 銘柄ごとの良い点・注意点
4. ポートフォリオへの影響（重複・偏り）
5. 次の一手
6. 出典リンク
7. 「一般的な情報整理で、投資助言ではありません」の一文

## してはいけないこと

- 確認していない数字を推測で断定する（推定なら「推定」と明記する）
- 「必ず上がる」「買うべき」と断言する
- テンバガーや短期の値上がりを約束する
- ユーザーの保有額・資産額をリポジトリにコミットする
