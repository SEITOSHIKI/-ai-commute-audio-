# スコアリング基準

5軸を各0〜3点で採点し、合計（最大15点）で順位を付ける。
同点のときは「配当利回り」→「業績の勢い」の順で比べる。

| 軸 | 3点 | 2点 | 1点 | 0点 |
|---|---|---|---|---|
| 配当利回り | 4%以上 | 2.5〜4% | 1.5〜2.5% | 1.5%未満 |
| 割安さ（予想PER） | 15倍未満 | 15〜22倍 | 22〜30倍 | 30倍以上 |
| 業績の勢い | 上方修正・2桁増益 | 増益 | 横ばい | 減益・下方修正リスク |
| テーマ性 | 複数の成長テーマにまたがる | 1つの成長テーマの本命 | 周辺 | なし |
| 買いやすさ（1株の金額） | 5,000円未満 | 5,000〜1万円 | 1万〜3万円 | 3万円以上 |

## 補正

- 一時的な利益（事業売却益など）でPERが低く見える → 割安さを1点下げる
- 配当が業績連動で減配予想 → 配当利回りを1点下げる
- 累進配当・DOE下限がある → 配当利回りを1点上げる（上限3点）
- 既存の保有と同じリスク（業種・テーマ）→ 合計から1点引き、理由を書く
- 除外業種 → ランキングから外す

## 分類

| 合計 | 位置づけ |
|---|---|
| 11点以上 | 今のポートフォリオに足しやすい |
| 8〜10点 | テーマ重視なら候補 |
| 5〜7点 | 決算や株価の調整を待つ |
| 4点以下 | 今の予算・方針には合わない |

## 金利感応度タグ

各銘柄に付けてポートフォリオのバランスを見る。

| タグ | 例 |
|---|---|
| 金利上昇に強い | 銀行、保険 |
| 普通 | 食品、日用品、商社、自動車部品 |
| 金利上昇に弱い | 住宅、不動産、REIT、借入の多い通信、高PERの成長株 |
