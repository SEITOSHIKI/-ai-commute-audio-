# 検証チェックリスト

調査で数字を出す前に、毎回確認する。

## 数字の整合性
- [ ] 株価・PER・利回りに取得日を付けたか。サイトごとに日付がずれていないか
- [ ] **株式分割**がないか。株価が以前の1/n になっていたら分割を疑う
      （例：東京海上は2026年10月に1→15分割。配当も1/15で読み替える）
- [ ] 配当利回り ＝ 年間配当 ÷ 株価 で検算したか。8%超など不自然なら分割や記載ミスを疑う
- [ ] 純利益が営業利益を大きく上回っていないか（事業売却などの一時利益）
- [ ] 前期が赤字で今期が急回復なら、その理由を確認したか

## 銘柄の基本
- [ ] 上場しているか（非上場は買えない。例：村田機械、東芝、Sakana AI）
- [ ] 事業の実態がテーマと一致しているか（例：富士通はPC事業をレノボとの合弁に移していて、AI PCの恩恵は小さい）
- [ ] 次回決算日はいつか。直前なら「決算後に判断」を勧める

## 配当
- [ ] 配当方針（配当性向・DOE・累進配当・業績連動）
- [ ] 権利確定日。過ぎていれば今年度の受取は期末分のみ
- [ ] 米国株は配当に米国の税金10%がかかり、NISAでも取り戻せない

## NISA・注文
- [ ] NISA口座で配当を非課税にするには「株式数比例配分方式」が必要
- [ ] NISAの損失は他の利益と相殺できない → 値動きの激しい小型株は特定口座も選択肢
- [ ] 売った枠の復活は翌年。短期売買には向かない
- [ ] 単元未満株の注文か（100株単位の通常注文と間違えない）
