# 資料のつくり方

## 二段構え
- **本編**：結論と一行の式だけ。右上に「計算の詳細：詳細版 p.○」。事業計画に慣れた人はこれで追える
- **計算詳細版**：式の中身・前提・出典。質問されたらそのページを開く。一般の聞き手は、省いた式や仮定が無いと納得できないので、別冊で必ず用意する
- **やさしい版**：数字に慣れていない人向けに、同じ数字をマンガで。数字は計算モデルから出す

## 本編の章立て（課題の設問①〜⑤の例）
| 設問 | ページの例 |
|---|---|
| ① 事業・理由・想い | 事業概要／選んだ理由と想い／背景／課題（困っている三者）／損失の大きさ／解決策／お客様の効果／デモ／端末と使い方／競合／大手との違い |
| ② スタッフ | 役割ごとの人数・任せる仕事・求める特性・自分の役割 |
| ③ 経営理念 | 使命・大切にする3つのこと・それぞれへの約束（ホームページの内容として） |
| ④ 年単位の計画と収支 | 市場／ターゲット／ビジネスモデル／収益モデル／売り方／売上と費用／損益分岐点／資金計画／黒字化の条件と撤退ライン／年単位の計画表／10年の見通し |
| ⑤ 段階ごとの課題 | 準備期・導入期・成長期・成熟期の課題／実現可能性の見直し／準備期の6か月／リスク |
| 締め | 最後に（事業への向き合い方・残したいもの）「ご清聴ありがとうございました」 |

1枚目の次に「設問と答えの対応表」を置くと、審査する人が追いやすい。

## 16枚版への統合（10分・A4用紙2枚）
本編の2〜3枚を1枚にまとめる。式・表・前提は残す（PIVOT風に大きな見出しと数字だけにしたら「浅い」と言われた）。

| 16枚版 | 統合する本編のページ |
|---|---|
| 1 表紙と構成 | 表紙・設問対応 |
| 2 事業概要と選んだ理由 | 事業概要・理由と想い |
| 3 背景と課題 | 背景・課題・損失 |
| 4 解決策とデモ | 解決策・育つAI・デモ |
| 5 使い方と端末 | 手元AR・端末と使い方 |
| 6 競合と差別化 | 競合・大手との違い |
| 7 スタッフ | スタッフ |
| 8 経営理念 | 経営理念 |
| 9 市場とターゲット | 市場・ターゲット・売り方 |
| 10 お客様の効果 | 導入効果 |
| 11 当社の収益 | ビジネスモデル・収益モデル |
| 12 年単位の計画と収支 | 売上と費用・損益分岐点・年単位の計画 |
| 13 資金と黒字化の条件 | 資金計画・黒字化の条件 |
| 14 10年の見通し | 10年で見ると |
| 15 段階ごとの課題と弱いところ | 段階ごとの課題・実現可能性・リスク |
| 16 準備期と最後に | 準備期の6か月・最後に |

## 文字の大きさと印刷
- 本文は9〜11pt、表は8.5〜9.5pt、注記は7.5pt。見出しは18〜19pt
- 1ページ4枚（A4横2×2）なら1枚の幅は約14cm。表の文字まで読める。1ページ8枚（A4縦2×4）だと本文は印刷で3〜4ptになる
- 見出しは1行に収める（全角で約28字まで）。折り返したら言葉を削る
- 全ページを画像にして、はみ出し・重なり・折り返しを目で確かめる

## デザイン（`assets/theme_drawing.js`）
- 図面の外枠と、右下の表題欄（章・ロゴ・頁）。見出しの番号は紺の四角に入れ、見出しの下に表題線
- 色は紺・青・安全色。判断基準の表は「進む」を緑、「直す・止まる」を赤、赤字の数字は赤
- 表は紺の見出し行に白文字。強調行は薄い青
- 表紙に事業と本人の背景に関係する図（例：地中送電ケーブルの断面）を置くと、その人らしさが出る
- 避ける：黒い箱の多用、ベージュや銅色の差し色、細い黒罫線とグレーの小さな注記ばかりの組み合わせ（AIが作った資料に見える）

## 台本（各スライドのノート）
- 「【開始 - 終了】／要約：一言／本文」の形。時間は1分約300字で自動計算する
- `scripts/notes_html.py` で、スライド画像の下に台本を付けたA4のPDFにする

## 16枚版で気をつけること（聞き手に業界外の人がいるとき）
- 想いは最後ではなく2枚目に置く。「なぜこの人がやるのか」を先に渡すと、後の数字が「この人の約束」として聞かれる
- 解決策は、作業の画面をいきなり見せない。「見つける・直す・まとめる」のような3つの動きを図にして、業界外の人にも何が変わるかを先に言う。差別化は同じページの一言で
- 推計の数字（市場規模など）は「〜と推定しています」と言い、言い切らない
- 「元が取れる条件」は主語（お客様が）を入れる

## サービス説明資料（お客様向け、発表とは別の冊子）
16枚版に入りきらない「実利・用途・使う場面」を、お客様の立場ごとに説明する。聞き手は、現場の方（職長・施工管理者など、使う人）と経営の方（部長・社長・DX担当など、払う人）。

| ページ | 中身 |
|---|---|
| 1 表紙 | 一文のサービス説明と、数字3つ（1台の削減時間・1拠点の効果・お客様が元を取る条件） |
| 2 困りごと | 立場ごとの列（使う人・管理する人・経営）。どれも「人を増やしても減らない時間」 |
| 3 変わること | いま／使った後／誰の時間、の表。やることが増えないことを言う |
| 4 1日の流れ | 朝から翌朝までの時刻と、その日に減る・残るもの |
| 5〜7 立場ごとの使い方 | 使う人：やること／やらなくていいこと。管理する人：届く書類の見本。教える人と教わる人：教材 |
| 8 現場の方へ | 監視ではないことの約束（記録する範囲・同意・評価に使わない・入力を増やさない）と、データの扱い |
| 9 経営の方へ | 効果の式・支払いとの比較・使う日数が減ったとき・元が取れる条件。手戻りなど会社ごとに違って測りにくい効果は数えない |
| 10 導入の進め方 | 試験導入の段階・合格ライン・当社とお客様の役割と費用 |
| 11 よくある質問 | 現場の方から・経営の方から、各4問 |
| 12 まずは1拠点から | 試験導入の条件と、数字の注意書き |

- 数字は計算モデルから出し、16枚版・計算詳細版と同じになるようにする
- 使う人が嫌がる仕組みは続かない。現場の方への約束を、経営の方のページより前に置く
- 画面や書類の見本は架空の工事で作り、そう書く

## 裏取りのExcel
計算詳細版の数字を、1つずつ式でたどれるブックにする。前提は1枚のシートにまとめ、他のシートは前提のセルを参照する式だけで作る（値の貼り付けで済ませない）。計算モデルの値を別の列に並べ、差が0になることを照合のシートで示す。PDFにも書き出して配れるようにする。
