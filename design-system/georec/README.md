# GEOREC Design System

株式会社ジオレック（GEOREC, Inc.）事業構想プレゼンのための設計基準。対象は 16:9・8枚・A4×2枚への 4-up 白黒印刷。画面より先に紙で読まれることを前提に、すべての値を決めている。

| ファイル | 中身 |
|---|---|
| `tokens.json` | 色・文字・余白・角丸・罫線・寸法のトークン（正本） |
| `tokens.css` | tokens.json から生成した CSS 変数と文字スタイルのクラス |
| `georec.css` | スライド部品のスタイル（`.gr-*`） |
| `pptx-theme.js` | pptxgenjs 用の定数（色は `#` なし6桁、長さはインチ、文字は pt） |
| `logos/` | ロゴ4点（マーク／ワードマーク × 黒版／白版）の SVG |
| `render-logos.mjs` | ロゴを PNG に書き出す（`npm i sharp` のうえ `node render-logos.mjs`） |
| `components/<部品>/` | 部品ごとの使い方と見本 HTML（`tokens.css` と `georec.css` を読み込んだ状態で表示する前提） |

数値・文言・スライド構成の正本は georec-deck スキル（SKILL.md）。この基準はその §1-1・§3・§4・§6 から抜き出したもの。

## 前提となる制約

- **白黒印刷で成立させる。** 色は `ink` `gray-700` `gray-500` `rule` `fill` `paper` の6値のみ。意味の区別は文字・太字・罫線・配置で行い、濃淡だけに頼らない。
- **4-up 縮小（約50%）でつぶれない。** 細すぎる罫線、角丸、影、グラデーション、装飾パターンを使わない。罫線は `stroke-rule` 以上。
- **スライドは 960×540px（10×5.625in）。** 余白・間隔は 0.05in 刻みの `space-*` で、pptxgenjs のインチ座標と一対一に対応する。
- **8枚を超えない。** 情報が入らないときは要素を足さず、文言を削る。

## 文章の基準

スライドは名詞句・体言止め・表・数式で組む。話し言葉はすべてノート欄へ移す。語彙は省庁の白書・審議会資料の水準にそろえる。

| 使う | 使わない |
|---|---|
| 記録は目的ではなく燃料 | 記録は目的じゃなくて燃料なんです |
| 創業者が律速になる → 現場ヒアリングを手順書化 | 自分がボトルネックにならないよう頑張りましょう |
| 設問④　経営計画 ─ 5年収支、黒字化の条件、必要資金 | 経営計画です。 |

- 見出しの末尾に句点を打たない。区切りは全角スペースと「─」。
- 「〜しましょう」「〜ですね」「とても」「すごく」を使わない。
- 弱み（創業者依存、営業・資金調達が未経験）を隠さず書く。
- 数字は SKILL.md §2 から機械的に導出できるものだけを載せる。新しい数字を足さない。
- タグラインは「掘る前に、わかる。」。旧タグライン「現場の言葉を仕組みに変える」は使わない。

## 色

| トークン | 値 | 役割 |
|---|---|---|
| `ink` | #1A1A1A | 本文・見出し・数値、黒ベタ面 |
| `gray-700` | #4D4D4D | リード文、注記、出典、算出根拠列 |
| `gray-500` | #8C8C8C | フッタ（タグライン・ページ番号）のみ |
| `rule` | #BFBFBF | 表の行罫、カード枠、サマリ区切り |
| `fill` | #F2F2F2 | 表ヘッダ、カード地、価格ストリップ |
| `paper` / `on-ink` | #FFFFFF | スライド地、黒ベタ上の文字とロゴ |

- 本文は `ink` on `paper`。補足は `gray-700`。`gray-500` は 3.4:1 のため 8.5pt のフッタ以外の文字に使わない。
- 黒ベタ（`ink` 面）は意味を持つ面に限る：表紙左1/3、理念の黒帯、ステージ列ヘッダ、締めボックス、SWOT ラベル。
- スライド幅いっぱいの装飾バー、カード片側のアクセントストライプ、タイトル下のアクセント罫線を使わない。

## 文字

フォントは Meiryo（Windows PowerPoint で確実に出る）。`--font-sans` は Meiryo → ヒラギノ角ゴ → Noto Sans JP → IPAゴシックの順に落ちる。英字ワードマークだけ `--font-latin`（Arial）。

| スタイル | 大きさ | 用途 |
|---|---|---|
| `tagline-display` | 36pt | 黒帯・表紙のタグライン |
| `cover-title` | 24pt | 表紙の主見出し |
| `slide-title` | 20pt 太字 | 各スライドの見出し |
| `figure` | 28pt 太字 | 数値カードの主数値 |
| `body` / `body-strong` | 14pt | 本文の下限、課題名 |
| `lead` | 12pt | 見出し直下のリード（`gray-700`、1行） |
| `table` / `table-strong` | 9.5pt | 表、カード内の補足、黒四角ラベル |
| `footer` | 8.5pt | 右下タグラインとページ番号（`gray-500`） |
| `note` | 8pt | 出典行、注記（`gray-700`） |

- 14pt 未満は表・注記・カード内補足に限る。本文に多用しない。
- 数値はすべて tabular-nums・右揃え。負値は「▲」、該当なしは「─」。
- 単位は表の左上に「単位：百万円」のように一度だけ書く。

## レイアウト

- 本文領域：左右 `space-8`（0.4in）、上 `space-6`、下はフッタ分を空ける。
- 見出し → リード → 本文ブロックの順。見出しとリードの間 `space-1`、リードと本文の間 `space-4`。
- ブロック同士の間隔は `space-3`。カード内パディングは `space-2`〜`space-3`。
- 角丸は `radius-0`。`radius-full` はロゴの円にだけ使う。
- 全ページ右上にロゴマーク（`corner-mark` 幅）、右下にタグラインとページ番号（`footer`）。同種スライドで見出し位置をそろえる。

## ロゴ

`assets/Logos/` のSVGを使い、描き直さない。白地には黒版、`ink` 面には白版。マークだけを使う場面（右上、黒帯）と、ワードマーク付き（表紙）を分ける。PowerPoint に入れるときは PNG に書き出す。

## pptxgenjs への写し方

- 色は `#` なし6桁（`"1A1A1A"`）。8桁・alpha 付きは使わない。
- 座標・寸法は `space-*` の px 値 ÷ 96 でインチにする（`space-8` = 0.4）。
- フォントサイズは pt 値をそのまま渡す（`slide-title` = 20）。
- 枠線は `stroke-rule` = 0.75pt、`stroke-strong` = 1.5pt。

## 検証

書き出した PDF を画像化し、1枚ずつ確認する：はみ出し、枠越え、重なり、表の列幅、見出し位置の揃い、グレースケールだけで読めること、数字が SKILL.md §2 と一致すること。
