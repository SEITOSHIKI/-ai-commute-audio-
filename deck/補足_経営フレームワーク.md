# 三現ワークス 補足資料：経営フレームワークでの整理

スライドは8枚（A4×2枚・4-up）の制約があるため、説得力に直結するフレームワークだけを本編に入れ、残りをここにまとめる。質問されたときの答えの元として使う。数値はすべて本編の経営計画から導出したもので、新しい数字は足していない。

## 本編に入れたもの

| スライド | フレームワーク | 使い方 |
|---|---|---|
| 3 解決策 | 製品戦略 | 基盤（記録・検索）が先、追加機能は年1本ずつ（ランド＆エクスパンド） |
| 3 解決策 | KM（ナレッジマネジメント） | ②整理する＝SECIモデルの「表出化」（暗黙知→形式知）。スライドには書かず、質問されたら説明する |
| 4 収益の仕組み | 価格戦略 | 価値基準価格。年300万円＝顧客効果2,880万円の約1割 |
| 5 競合 | ポジショニングマップ | 横軸＝実績／判断の理由、縦軸＝人の時間／仕組み。右上が空いている |
| 5 競合 | STP | S＝工程の形で区分、T＝電線・ケーブル工場、P＝判断の理由を人と機械に渡す層 |
| 5 競合 | コトラーの競争地位戦略 | ニッチャー。大手が採算に乗せにくい専門領域に絞る |
| 5 競合 | ポーターの基本戦略 | 差別化集中。コストリーダーシップは取らない |
| 5 競合 | ERP・MES・SCM | 置き換えず、API連携で併存する |
| 7 経営計画 | CVC | 必要資金1.5億円の調達先。資金と実証フィールド・販路を同時に得る |
| 8 リスク | アンゾフの成長マトリクス | 中期の母数不足に「新市場開拓」（施工会社へ同じ基盤）で対応 |
| 8 リスク | CRM | 利用ログを顧客管理に載せ、解約兆候を早期に検知 |
| 8 リスク | BSC・CSF・KPI | 4視点の指標を先に決め、創業者がいなくても判断できるようにする |

## ビジネスモデルキャンバス

| ブロック | 内容 |
|---|---|
| 顧客セグメント | 電線・ケーブル工場の生産技術・製造部門（主軸）。後に、その製品を施工する工事会社 |
| 価値提案 | 熟練者の勘を言語化し、教材（研修資料・音声番組・動画）と仕組みにして次の担い手に渡す。日本の品質を支える現場の勘を、人に依存しない遺産として残す |
| チャネル | 直販（創業者と営業）。CVC出資元の電線・ロボットメーカー経由の紹介 |
| 顧客との関係 | 導入支援（約2か月）→カスタマーサクセスによる定着支援。データは顧客のもの、囲い込まない |
| 収益の流れ | 基盤100万円＋登録20万円×平均5＋モジュール50万円×平均2本＝1拠点年300万円。初年度のみ導入支援200万円 |
| 主要リソース | 現場データ基盤、蓄積した判断記録、製造・施工の現場を知る人材 |
| 主要活動 | 熟練者への聞き取りと形式知化、教材の制作・配信（生成AIで台本→当社が監修）、記録アプリ・基盤・追加機能の開発、導入支援 |
| 主要パートナー | 電線メーカー（実証フィールド）、搬送ロボット・検査AIベンダー（FLOWの連携先）、MES・ERPベンダー（API連携） |
| コスト構造 | 人件費（1人800万円／年）が中心。ライセンス原価率15%（粗利率85%）、導入支援・受託は原価率60%（粗利率40%） |

## PPM・事業ポートフォリオマネジメント

単一事業の創業期にPPMを当てはめても意味は薄い。モジュールが揃う4年目以降に、モジュール単位で使う。

| 区分 | 該当 | 方針 |
|---|---|---|
| 金のなる木 | 基盤ライセンス | 全顧客が払う。原価率15%で安定収益 |
| 花形 | KNACK（1年目・教材制作）・SAFE（2年目・危険箇所表示） | 技能継承の需要が強く、採用が伸びる想定 |
| 問題児 | TWIN（3D仮想工場）・DRAW（音声作図）・HAPTIC／FLOW（研究開発） | 市場は伸びるが、ロボット・AIベンダーとの連携次第。投資判断は採用率で決める |
| 負け犬 | 受託開発 | プロダクト化できない個別案件。5年目に売上の3%まで落とす |

## 多角化について

アンゾフの成長マトリクスで、取る順番と取らないものを決めている。

1. **市場浸透**（1〜3年目）：電線・ケーブル工場に基盤とモジュールを入れる
2. **新製品開発**（毎年）：モジュールを年1本ずつ追加する
3. **新市場開拓**（4〜5年目）：製品の出口である施工会社へ同じ基盤を展開する
4. **多角化**：5年以内は取らない。ニッチャーとして集中を崩さないため

## ベンチマーキング・ベストプラクティス

- **ベンチマーク先**：建設業向けSaaS（契約1,593社・解約率0.6%、SpiderPlus & Co. 決算説明資料）。中小の現場に定着させた導入・解約の管理方法を参考にする
- **ベストプラクティス**：製造業の技能継承は、再雇用で熟練者に残ってもらう方法が最も多い（ものづくり白書2026）。当社はこれを置き換えず、熟練者が在籍しているあいだに判断理由を記録する手段として売る

## R&D（技術開発戦略）

研究開発は独立部門を持たず、エンジニア（2名→9名）が担う。製品化前の売上は計画に含めない。

- **作らない**：音声記録・AIによる構造化は汎用技術（競合も同じ設計）。自前開発は最小限にする
- **作る**：連続工程の工程データ（ロット・押出温度・線速・試験値）と現場処置の紐づけ、教材化の手順
- **組む**：CAD（音声作図）・3D（仮想工場）・触覚デバイスはベンダー・大学と共同研究
- **試作済み**：ニュースを要約→音声合成→ポッドキャストとして毎朝自動配信する仕組みを個人で実装済み

| 時期 | 名称 | 渡し方 | 状態 |
|---|---|---|---|
| 1年目 | 基盤 | スマートグラスでの会話・画像の常時収録、進捗の自動報告、過去事例の検索 | 製品 |
| 1年目 | KNACK | 勘どころの音声番組・動画・研修資料を当社が制作（差別化の中心） | 製品 |
| 2年目 | SAFE | 危険箇所・過去のヒヤリ地点をスマートグラスに表示 | 製品 |
| 3年目 | GLASS | 図面・作業手順を現物に重ね、差異を検出 | 製品 |
| 4年目 | TWIN | 設備の内部構造・工場全体を3Dで再現（グラスで浮かび上がらせる元データ） | 製品 |
| 5年目 | DRAW | 登録したパターンを音声指示でCAD作図（現場調査中に図面化） | 製品 |
| 研究 | HAPTIC・FLOW | 力加減の訓練シミュレーター／搬送ロボット・検査AIとの連携 | R&D |

## BSC（本編スライド8の詳細）

| 視点 | CSF（重要成功要因） | KPI |
|---|---|---|
| 財務 | 顧客の増加が人員の増加を追い越す | 社員1人あたり顧客拠点 2.8以上（4年目に3.67） |

## 想定問答（フレームワーク関連）

1. **なぜニッチャーなのか** → 電線業界は353事業所と小さく、大手SIerやロボットベンダーにとって採算に乗せにくい。だから専門性で先に押さえられる。
2. **なぜコストリーダーシップを取らないのか** → 創業期は規模がなく、価格で勝つ根拠がない。現場の知見で選ばれる差別化集中のほうが、顧客効果の約1割という価格を守れる。
3. **市場が小さすぎないか** → その通りで、中期の課題に置いている。対策はアンゾフの新市場開拓で、製品の出口である施工会社へ同じ基盤を広げる。
4. **CVCから出資を受けると独立性を失わないか** → 出資比率を抑え、データは顧客のものという方針を契約で守る。得たいのは資金より実証フィールドと販路。
5. **BSCは小さな会社に重すぎないか** → 指標は4つだけに絞っている。目的は管理ではなく、創業者がいなくても判断できる基準を先に決めておくこと。

## 内製化の先行事例（スライド5の根拠）

「判断の理由を仕組み化する」取り組みは、事業会社の内製でも存在する。ただし公開事例は、大手が大手SIerと組んだ個別開発に偏っている。電力インフラ（電線・送配電・電気工事）では、公開事例は見当たらなかった（見当たらないことは、存在しないことを意味しない）。

**読み取れること**
- 先行しているのは大手のみ。中堅の工場は、同じことをする予算と人手がない → 当社のターゲット
- 動画マニュアル系のSaaS（tebiki、Teachme Biz）は手順を伝える道具で、判断の理由とロット・設備データは扱わない。教材の制作も顧客側の作業になる
- 想定問答：「勤務先も同じことをしているのでは？」→ 公開情報では構想段階。だからこそ、社内で生産技術・情報システムの立場から形にしたい（キャリア接続）

## 事業戦略の見直し（類似企業調査を踏まえて・2026年10月8日）

### 何が分かったか
- **「貯める」は差別化にならない**：Airion「技能継承くん」（2025年7月）が、音声・チャットでベテランの知識を記録し、AIで構造化している。当社の①記録・②整理とほぼ同じ設計
- **組立×図面はキャディが押さえている**：CADDi（2026年8月6日 次世代版）は設計意図・判断履歴を自動データ化。日経225のディスクリート系製造業の過半数に導入済み
- **教材の自動生成は混み始めている**：社内資料から研修を自動生成するサービスが2026年に複数登場

### どう変えたか
| 項目 | 変更前 | 変更後 |
|---|---|---|
| 差別化の中心 | 記録・整理（データ基盤） | 渡す（教材にして届ける）。記録・整理は手段 |
| 教材化（KNACK）の提供時期 | 2年目 | 1年目（差別化の中心を最初から出す） |
| 技術開発 | 記録の構造化を自前で作る | 汎用部分は作らない。工程データとの紐づけと教材化の手順に集中 |
| 狙う市場 | 電線工場 | 工程の形で区分し、連続工程（電線）×中堅に絞る。組立はCADDiの領域として避ける |
| 防御線 | 蓄積した判断記録 | 図面に現れない現場処置の蓄積＋現場で監修できる人 |
| 最大の脅威 | 大手SIer・ロボットベンダー | CADDiの連続工程への参入 |

収支の数字（顧客拠点数・価格・人員・損益）は変えていない。教材制作の作業は、追加機能の料金とカスタマーサクセスの人員の範囲で賄う前提。

### 採らなかった選択肢（質問されたとき用）
- **Airionなどと連携し、「貯める」は他社に任せる**：開発費は下がるが、工程データとの紐づけができず、教材の質を担保しにくい。中期に再検討する余地はある
- **教材制作の受託だけに絞る**：参入しやすいが、労働集約で粗利率40%にとどまり、積み上がる利用料がなくなる

## 想定問答（競合）

1. **Airionの「技能継承くん」と同じでは？** → 貯めるところまでは同じ設計です。東大発のスタートアップが同じ設計に至っていることは、この課題に市場がある証明だと考えています。分かれるのは渡し方です。指導する人材が不足している事業所は59.5%、育成の時間がない事業所は47.4%（厚労省 能力開発基本調査）。貯めたデータから教材を作る工程が現場に残ったままでは使われません。当社はそこを引き取ります。
2. **キャディのCADDiが降りてきたらどうするのか？** → 最大の脅威です。同社も「製造業の叡智の8割以上は人の頭の中の暗黙知にある」と述べており、課題認識は同じです。ただし対象は組立の製造業で、扱うデータは図面とBOMが中心です。「湿度が高いので押出温度を2℃下げた」という処置と理由は、図面には現れません。防御線は、蓄積した現場処置の記録そのものです。機能は模倣できても、現場の履歴は移設できません。
3. **教材の自動生成サービスも出てきているが？** → 生成そのものは差別化になりません。防御線は、電線工場の連続工程という文脈を持っていることと、当社の担当者が現場に入って監修することです。生成した教材が現場で通用するかを判定できる人がいるかどうかが分かれ目です。

## スマートグラスを中心にした解決策（2026年10月8日 追加）

| 段階 | 誰のため | 内容 |
|---|---|---|
| ① 自動で記録 | 熟練者 | 作業中の会話と作業対象の画像をスマートグラスが常時収録。記録のための作業はゼロ |
| ② 整理する | ─ | 生成AIが会話と画像から条件・処置・理由を取り出し、ロット・設備データ・図面と紐づける |
| ③ 渡す（その場で） | 若手 | 設備の構造を浮かび上がらせ、図面・作業手順・作業指示と現物を照合し、差異を表示 |
| ③ 渡す（報告） | 管理者 | 会話と画像から作業内容を判定し、進捗を自動で報告。日報の手間を減らし、報告を早め、現場に行かなくても状況が分かる |
| ③ 渡す（後から） | 次の担い手 | 勘どころを音声番組・動画・研修資料にして当社が制作 |

**ROIとのつながり**：顧客効果の前提「1人月6時間の削減」は、日報・進捗報告などの書類作業の削減分。自動報告がこれを置き換えるため、建設業の書類電子化実績（月6.5時間）を準用する根拠が強くなった。

## 想定問答（スマートグラス）

1. **会話を常時録音されるのは、現場が嫌がるのでは？** → 収録は作業時間・作業エリアに限り、本人同意と労使の合意のもとで行います。目的は監視ではなく、記録と報告の手間をなくすことだと最初に説明し、休憩中や私語は自動で除外する設計にします。
2. **スマートグラスの端末代は誰が払うのか？** → 端末は市販品を顧客が購入する前提で、当社の価格（年300万円）と投資回収の試算には含めていません。当社は中身とアプリに集中します。
3. **AR作業支援の製品はすでにあるのでは？** → 手順を表示する製品は各社にあります。当社は、会話から自動で貯めた熟練者の判断を、連続工程の図面・手順と一緒に現物に重ねる点と、管理者への自動報告、教材化まで一続きで行う点で分かれます。
