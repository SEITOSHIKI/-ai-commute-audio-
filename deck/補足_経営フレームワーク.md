# 三現ワークス 補足資料：経営フレームワークでの整理

スライドは8枚（A4×2枚・4-up）の制約があるため、説得力に直結するフレームワークだけを本編に入れ、残りをここにまとめる。質問されたときの答えの元として使う。数値はすべて本編の経営計画から導出したもので、新しい数字は足していない。

## 本編に入れたもの

| スライド | フレームワーク | 使い方 |
|---|---|---|
| 3 解決策 | 製品戦略 | 基盤（記録・検索）が先、追加機能は年1本ずつ（ランド＆エクスパンド） |
| 3 解決策 | KM（ナレッジマネジメント） | ②整理する＝SECIモデルの「表出化」（暗黙知→形式知）。スライドには書かず、質問されたら説明する |
| 4 収益の仕組み | 価格戦略 | 価値基準価格。年300万円＝顧客効果2,880万円の約1割 |
| 5 競合 | ポジショニングマップ | 横軸＝実績／判断の理由、縦軸＝人の時間／仕組み。右上が空いている |
| 5 競合 | STP | S＝工程の形で区分、T＝電線・ケーブル工場、P＝判断の理由を人と機械に渡す層 |
| 5 競合 | コトラーの競争地位戦略 | ニッチャー。大手が採算に乗せにくい専門領域に絞る |
| 5 競合 | ポーターの基本戦略 | 差別化集中。コストリーダーシップは取らない |
| 5 競合 | ERP・MES・SCM | 置き換えず、API連携で併存する |
| 7 経営計画 | CVC | 必要資金1.5億円の調達先。資金と実証フィールド・販路を同時に得る |
| 8 リスク | アンゾフの成長マトリクス | 中期の母数不足に「新市場開拓」（施工会社へ同じ基盤）で対応 |
| 8 リスク | CRM | 利用ログを顧客管理に載せ、解約兆候を早期に検知 |
| 8 リスク | BSC・CSF・KPI | 4視点の指標を先に決め、創業者がいなくても判断できるようにする |

## ビジネスモデルキャンバス

| ブロック | 内容 |
|---|---|
| 顧客セグメント | 電線・ケーブル工場の生産技術・製造部門（主軸）。後に、その製品を施工する工事会社 |
| 価値提案 | 熟練者の判断を記録し、次の担い手と機械に渡す。人が減っても迷わず回る現場 |
| チャネル | 直販（創業者と営業）。CVC出資元の電線・ロボットメーカー経由の紹介 |
| 顧客との関係 | 導入支援（約2か月）→カスタマーサクセスによる定着支援。データは顧客のもの、囲い込まない |
| 収益の流れ | 基盤100万円＋登録20万円×平均5＋モジュール50万円×平均2本＝1拠点年300万円。初年度のみ導入支援200万円 |
| 主要リソース | 現場データ基盤、蓄積した判断記録、製造・施工の現場を知る人材 |
| 主要活動 | 熟練者への聞き取りと形式知化、記録アプリ・基盤・追加機能の開発、導入支援 |
| 主要パートナー | 電線メーカー（実証フィールド）、搬送ロボット・検査AIベンダー（FLOWの連携先）、MES・ERPベンダー（API連携） |
| コスト構造 | 人件費（1人800万円／年）が中心。ライセンス原価率15%（粗利率85%）、導入支援・受託は原価率60%（粗利率40%） |

## PPM・事業ポートフォリオマネジメント

単一事業の創業期にPPMを当てはめても意味は薄い。モジュールが揃う4年目以降に、モジュール単位で使う。

| 区分 | 該当 | 方針 |
|---|---|---|
| 金のなる木 | 基盤ライセンス | 全顧客が払う。原価率15%で安定収益 |
| 花形 | KNACK（2年目）・TRACE（3年目） | 技能継承の需要が強く、採用が伸びる想定 |
| 問題児 | TWIN・FLOW | 市場は伸びるが、ロボット・AIベンダーとの連携次第。投資判断は採用率で決める |
| 負け犬 | 受託開発 | プロダクト化できない個別案件。5年目に売上の3%まで落とす |

## 多角化について

アンゾフの成長マトリクスで、取る順番と取らないものを決めている。

1. **市場浸透**（1〜3年目）：電線・ケーブル工場に基盤とモジュールを入れる
2. **新製品開発**（毎年）：モジュールを年1本ずつ追加する
3. **新市場開拓**（4〜5年目）：製品の出口である施工会社へ同じ基盤を展開する
4. **多角化**：5年以内は取らない。ニッチャーとして集中を崩さないため

## ベンチマーキング・ベストプラクティス

- **ベンチマーク先**：建設業向けSaaS（契約1,593社・解約率0.6%、SpiderPlus & Co. 決算説明資料）。中小の現場に定着させた導入・解約の管理方法を参考にする
- **ベストプラクティス**：製造業の技能継承は、再雇用で熟練者に残ってもらう方法が最も多い（ものづくり白書2026）。当社はこれを置き換えず、熟練者が在籍しているあいだに判断理由を記録する手段として売る

## 経営管理システムの使い分け

| システム | 当社での位置づけ |
|---|---|
| ERP | 顧客側の基幹（受注・原価）。置き換えず、ロット原価の参照先としてAPI連携 |
| MES | 顧客側の生産実績。置き換えず、実績データの取得元として連携 |
| SCM | 材料ロットと納入先の情報源。TRACEが参照する |
| SFA | 自社の営業管理。営業は3年目から1〜2名のため、商談管理は軽量なもので足りる |
| CRM | 自社の顧客管理。利用ログと合わせて解約兆候を検知する（中期の課題への対策） |
| KM | 事業の中心。KNACKはSECIモデルの表出化を製品にしたもの |

## R&D

研究開発は独立部門を持たず、エンジニアがモジュール開発として担う（2名→9名）。基礎研究はせず、フィジカルAI・画像検査など外部の技術は連携で取り込む。

## BSC（本編スライド8の詳細）

| 視点 | CSF（重要成功要因） | KPI |
|---|---|---|
| 財務 | 顧客の増加が人員の増加を追い越す | 社員1人あたり顧客拠点 2.8以上（4年目に3.67） |
| 顧客 | 導入初年度に効果が見える | 初年度費用の回収 約2.1か月 |
| 業務プロセス | 個社対応で受託化しない | 導入期間2か月／共通機能8割 |
| 学習と成長 | 創業者が律速にならない | 創業者が1か月不在でも事業が継続（5年目） |

## 想定問答（フレームワーク関連）

1. **なぜニッチャーなのか** → 電線業界は353事業所と小さく、大手SIerやロボットベンダーにとって採算に乗せにくい。だから専門性で先に押さえられる。
2. **なぜコストリーダーシップを取らないのか** → 創業期は規模がなく、価格で勝つ根拠がない。現場の知見で選ばれる差別化集中のほうが、顧客効果の約1割という価格を守れる。
3. **市場が小さすぎないか** → その通りで、中期の課題に置いている。対策はアンゾフの新市場開拓で、製品の出口である施工会社へ同じ基盤を広げる。
4. **CVCから出資を受けると独立性を失わないか** → 出資比率を抑え、データは顧客のものという方針を契約で守る。得たいのは資金より実証フィールドと販路。
5. **BSCは小さな会社に重すぎないか** → 指標は4つだけに絞っている。目的は管理ではなく、創業者がいなくても判断できる基準を先に決めておくこと。
