2. **なぜあなたなのか** → 施工管理5年で現場を知り、独学で仕組みを作って動かしてきた。音声の自動配信は今も毎朝動いている（実物を見せられる）。
3. **営業・資金調達の経験は** → ない。だから最初の3拠点は有償試験導入に絞り、実証データで売る。弱みは隠さない。
4. **前職との関係は大丈夫か** → 前職の顧客・機密は使わない。退職時の合意（競業避止・守秘）を確認し、紹介は第三者経由にする。【要確認】在籍状況と合意の内容。
5. **チームは決まっているのか** → 【要記入】現時点で確定しているのは創業者1名。技術責任者・電気工事の施工管理経験者・顧問の状況（確定・内諾・打診中・募集中）を正直に答える。投資家は「最重要」として必ず突く。

## お客様の得（計算詳細版 p.5〜8）
6. **お客様はいくら得するのか** → 得をするのは端末を着けた班だけ。1拠点10台×年240日×1台1日35分（職長の日報・撮影15分＋施工管理者の写真整理・写真台帳20分）で年約479万円。お客様が払うのは当社300万円＋端末リース約53万円の約353万円なので約1.4倍。
7. **元が取れる条件は** → 353万円÷（10台×240日）÷1時間の人件費で、1台1日約26分。想定35分はこれを上回るが余裕は大きくない。26分を実証の合格ラインにする（p.8）。
8. **1時間の人件費の根拠は** → 賃金構造基本統計調査の年収（電工約551万円、施工管理者は建築・土木技術者で代用して約620万円）×会社負担1.16÷建設業の年間総実労働時間（残業込み）約2,000時間で、電工約3,200円・施工管理者約3,600円。所定の1,950時間で割ると、残業代込みの年収を少ない時間で割るので単価が高く出る（p.5）。
9. **月6時間削減という数字は使わないのか** → 使わない。建設業の書類電子化の実績（月6.5時間）は原典を確認できておらず、ARグラスの効果とも違う。実証で導入前2週間と導入後4週間を比べて測る（p.6）。
10. **手戻りや新人指導の効果は** → 手戻りはARが効く工種（3割）に絞ると年約360万円。AIの出来と当社の監修しだいなので、実測できるまで計画に入れない（入れば約2.4倍）。新人指導は他の仕事と混ざって測れないので金額にせず、独り立ちまでの月数・付き添い時間・やり直し件数で測る（p.7）。
11. **時間が浮いても現金は増えないのでは** → その通り。時間は人件費換算の価値。現金になるのは、残業代が減ったとき、または浮いた時間で断っていた工事を受けたとき。実証では「残業時間」と「受注件数」も測る。
12. **それは思いの話ではないのか。国としての損失は** → 建設投資は2025年度見通しで約75.6兆円。手戻りは海外研究で工事費の0.4〜6%で、控えめに2%とすると建設全体で年約1.5兆円、電気工事だけで年約2,400億円。55歳以上の就業者は約175万人。熟練者が抜けるほど手戻りが増え、残業上限で人を足せない分、受けられる工事が減る。

## 値段と原価（計算詳細版 p.9〜13）
13. **値段の内訳は** → 会社の基盤 月5万円／拠点（データ保管庫・管理画面・図面と手順の登録・月次の効果レポート）＋端末ライセンス 月2万円／台（記録→写真抽出→日報・写真台帳。録画は月80時間まで）。標準10台で年300万円。初年度だけ導入支援200万円。

## 解決策・端末（計算詳細版 p.26）
38. **ANDPADやSPIDERPLUSがあるのでは** → あれは人が撮って入力する器。当社は一人称で自動に記録し、写真を抜き出して報告書を作り、図面と照合し、熟練者の判断を教材にする。競わずにつなぐ（報告書と写真は各社の形式で出力）。最大の脅威は各社がAIで自動報告を加えることで、防御線は図面に現れない判断の蓄積と、施工経験者による監修。製造業のAirion・CADDiは対象が違う（補足資料）。
39. **常時録音・録画は現場が嫌がる** → 作業時間・作業エリアに限定し、本人同意と労使合意のもとで行う。休憩中・私語は自動除外。目的は監視ではなく、記録と報告の手間をなくすこと。
40. **スマートグラスは自社で開発するのか** → 作らない。作るのはアプリ・AI・データ基盤と、端末を壊さない保護カバー・ヘルメット取付具。端末は「落下2m級・IP66級・1シフトの電池・ヘルメット装着・手袋のまま音声操作」を満たす市販品を選び、世代が進めば乗り換える。今すぐは産業用ヘッドマウント端末（例：RealWear Navigator 520）とヘルメットカメラ、2〜3年目に法人向けAR端末でジョイント1種類を実証、2027年以降は一般向けARグラス（発売は報道ベース）。
41. **照合（自動チェック）ができなくても意味があるのか** → ある。約2mのジョイントの組立図を壁に貼って往復している作業がなくなる。実物大・立体・工程ごとの完成形を手元に出し、ベテランの注意点を該当箇所に固定表示できる。寸法の最終確認はスケールで、ARは「測る道具」ではなく「理解して間違いに気づく道具」。効果は手戻り件数・1ジョイントの作業時間・独り立ちまでの期間で測る。
42. **なぜ今、作業者向けのAIなのか** → 考える・書くAIは事務作業で実用の水準に来た。次は肉体労働の暗黙知を「見るAI」で支える番。表示付きスマートグラスは2025年に発売され、ARグラスも一般発売が報じられている。2024年からの残業上限と高齢化で、人を増やして解決できない。
43. **ミス事例はどう生かすのか** → 過去のミス事例を学習させ、ミスしやすい場面（赤を切るか青を切るか、の瞬間）を現物で認識したら、音声で警告し、レーザーポインターで正しい位置を示す。

## 社名・ロゴ・所在地
44. **社名とロゴの意味は** → 社名カンツギは「勘継」。割れた器を金で継ぐ金継ぎのように、途切れそうな現場の勘をデータで継ぐ。ロゴは、四隅のカギ括弧がスマートグラス（AR）のファインダー、立方体の三つの面が現場・現物・現実、側面を走る銅色の線が金継ぎの継ぎ目、銅色の上面の点がデータになった勘で、開いた右上の角から次の担い手へ流れ出る。銅色は電線の導体の色。
45. **会社の所在地は** → 川崎市を提案。羽田空港・新幹線（品川・新横浜）に近く、関東一円の電気工事会社へ日帰りで出られる。オフィスは1年目15坪→5年目40坪（賃料＋共益費）。
