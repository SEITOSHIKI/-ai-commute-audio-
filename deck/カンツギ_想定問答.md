## 競合（本編 p.14）
48. **ANDPADやSPIDERPLUSがあるのでは** → あれは人が撮って入力する器。当社は一人称で自動に記録し、写真を抜き出して報告書を作り、図面と照合し、熟練者の判断を教材にする。競わずにつなぐ（報告書と写真は各社の形式で出力）。
49. **RealWearのような産業用ヘッドセットと何が違うのか** → 方向は近い。両手が空いたまま映像を記録し、遠くの熟練者とつなぐ点は同じ。ただ、映像を見て判断するのは遠隔の人で、報告書や教材にはならない。RealWearも音声で操作するAI（Arc 3のAri OS）や生成AIとの連携を始めており、脅威として見ている。当社は端末としてRealWearも選べるようにし、電気工事の判断の記録と施工経験者の監修で差をつける。
50. **日立のAI Safetyとほぼ同じでは** → 方向は同じと認める。日立製作所・日立ビルシステム・日立パワーソリューションズが2025年10月に発表し、ウェアラブルカメラの映像をVLMで解析して、安全アラート・チャットボット・作業ガイディング・報告書作成を目指す。11月から日立ビルシステムの全国の現場で数千人が運用。技術と規模では勝てない。だから領域をずらす：日立は大手の自社保守（ビル設備）と安全から、当社は中堅の電気工事会社の施工から入り、第一の価値は書類（発注者ごとの施工写真台帳・検査記録）の削減と技能の継承。安全アラートでは競わない（本編 p.15）。
51. **日立が施工や中堅向けに来たら** → 競わず提携も選ぶ（日立の基盤に電気工事の工種の型を載せる、協力会社へ広げる）。勝負の窓は2〜3年と見て、工種の型と監修付きのデータを先に貯める。日立の価格と外販の予定は未確認。

53. **段階ごとの課題は** → 準備期は効果が出るか、導入期は売れるか・定着するか、成長期は台数と人、成熟期は競合と次の市場。それぞれに進む条件を置いた。

## 日立パワーソリューションズ・10年・事業の姿勢（本編 p.14〜15・28・33）
58. **日立パワーソリューションズは何をしているのか** → 日立製作所と共同で、受変電設備の真空遮断器（VCB）の点検で、点検前後の写真をAIエージェント（Gemini Enterprise）が照合し、ボルトの向き・配線の誤り・放電クリップの外し忘れを警告する仕組みを検証中。今後は手書き記録のデータ化、映像での手順逸脱の検知、報告書の自動作成も計画。電気設備の領域なので、日立ビルシステムの AI Safety より当社に近い。
59. **日立はどうやって黒字にしているのか** → AIそのものを売って黒字にしているのではない。日立パワーソリューションズの稼ぎは、発電・変電設備の保守・点検・遠隔監視（O&M）の契約。AIは自社の保守員の品質を上げ、原価を下げる道具で、すでにある保守契約の中で回収している。日立製作所は別に、熟練者のノウハウを取り込んだAIエージェントの開発・運用サービスを個別見積で大企業に売っている（2025年3月〜）。
60. **日立も「現場の評価軸」をAIに学ばせる基盤を作っているのか** → 作っている。エスノグラフィーやAIインタビューで熟練者の判断基準を引き出してAIに反映し、図面・保全記録を学習データやRAGにする（保全向けで故障原因・対策の正答率90%以上と報道）。だから「判断を学ばせる」こと自体は差別化にならない。違いは、日立は1社ごとの個別開発（大企業・保守）、当社は中堅の電気工事会社に共通の「施工の工種の型」を月額で配ること。
61. **日立の稼ぎ方を真似できないか** → 部分的にはできる。日立型は「既存の保守契約にAIを組み込む」形。当社に保守契約はないので、真似るなら①書類まで仕上げるサービス（写真台帳・検査記録を当社が仕上げ、AIで原価を下げる。客単価は上がるが人手がかかる）、②保守・保安の会社（電気保安法人など）と組み、その点検契約にAIを載せる、の2つ。まずは利用料（今の計画）を基本にし、実証の3社に①の値段も聞いて比べる。
62. **10年で見るとどうか** → 5年目までの計画を変えずに延ばすと、1拠点10台のままでも6年目に黒字、8年目に5年間の赤字を取り戻す。10年目は207拠点・売上約6.6億円・営業利益約1.9億円。条件は6年目から採用のペースを落とすこと（社員24→32人）。採用1.3倍なら7年目、値下げ20%やAI費用2倍では現金がいったんマイナス（計算詳細版 p.30）。
63. **黒字にならなかったら続けるのか** → 利益は目的ではなく、続けるための条件。配当は求めず、利益は現場と開発に戻す。自己資金は見返りを求めない投資で、共感する工事会社・職人・業界団体と一緒に育てたい。ただし資金は有限なので、撤退ラインは守る。10年続ければ、書類に使っていた約137万時間（約49億円分）が現場と若手の指導に戻る（本編 p.33）。

## 計算詳細版の見直しで出た質問（10/20）
64. **販管費173百万円の「振替」は何か。5年目をプラスにするには何を動かすのか** → 振替は、導入支援と個社設定にかかった導入コンサルタントなどの人件費（約48百万円）。原価に入れたので販管費から引いている。5年目を黒字にするには、どれか1つで足りる：拠点を約6増やす（87拠点）、1拠点12台にする、社員を2人減らす（1人約810万円）。（計算詳細版 p.3・18）
65. **AI・保存の1台月6,000円の中身は。動画は何GBか** → 文字起こし2,200円（録音1日4時間×20日＝4,800分×$0.003。削減時間の35分とは関係なく、録音した時間に掛かる）、画像解析1,000円（月3,000枚）、報告書の生成200円、保存700円（大事な場面だけ月10GBを3年保存。平均180GB×$0.025。録画そのものは端末に残してクラウドに送らない）、転送・監視など1,900円。保存は4年目以降の定常で1台月約1,350円になる（+650円）。（p.11）
66. **画像1枚1,000トークンは少なくないか** → やや少ない。1280×720の写真は約1,230トークン（幅×高さ÷750）で、指示と出力を足すと約1,500トークン。Claude Haiku 5.5なら月約100円、Sonnet 5.5なら月約2,050円で、モデルの1,000円はその間。全部をSonnetにしても粗利率は約68%。（p.11）
67. **粗利率72%は良すぎないか。考えていないことは** → 原価に入れているのはクラウドとAIの費用だけで、定着支援（導入コンサルタント）と現場監修（印付け）の人件費は販管費に入れている。SaaSの慣行どおりそれらを原価に入れると、5年目の利用料の粗利率は約56%。分類を変えても営業利益は変わらない。（p.11）
68. **240日は多くないか** → 上限に近い見積。稼働日が200日なら効果は年約416万円・支払いの約1.25倍、元が取れるのは1台1日約28分。支払いは日数で変わらないので、日数が減るほど合格ラインは上がる。（p.6）
69. **手戻りの削減を数えないのはなぜか** → 手戻り率は会社ごとの現場事情で大きく違い、各社で実証しないと分からない。何を手戻りとするかに主観も入り、検証の費用が効果と釣り合わない可能性もある。だから計画にも提案の金額にも入れず、件数と原因を記録に残す。（p.7）
70. **動画の解析量がお客様のボトルネックにならないか** → 上限を超えても録画は止まらない（端末に残る）。解析量は「標準 月3,000枚・保存10GB、超えたら1,000枚ごと月2,000円・10GBごと月2,000円」のようなプランで選べるようにする（案）。追加の10GBは3年保存で原価が月約700円、たまり切ると月約1,350円なので、2,000円にしている。解析は当社の原価の中心なので、上限と追加料金で守る。（p.12）
71. **2年目から年300万円と言うが、お客様の支払いは332万円では** → そのとおり。当社の売上は利用料300万円で、お客様はこれにAIグラスのリース約32万円を払う。1年目は導入支援200万円を足して約532万円。（p.8・13）
72. **拠点を増やし過ぎるとコンサルタントが足りないのでは** → 1人年6拠点が上限なので、新規拠点の計画はコンサルの人数×6の内側に置いている（上限6・12・24・36・48、計画3・9・18・27・33）。商談を取りすぎても、受けるのは上限まで。営業は拠点と台数を増やす段階まで採用を遅らせる案もある。（p.13・16・17）
73. **解約率10%の根拠は。官公庁・電力会社が顧客だからか** → 根拠は弱い。海外の目安は大企業5〜10%・中小30〜50%で、中堅なのに低めに置いた理由は、記録が貯まるほど乗り換えにくいことと、電力会社・官公庁の写真台帳は書式が決まっていて一度合わせると変えにくいこと。解約20%なら5年目は約▲31百万円。1年目の継続率で更新する。（p.14・21）
74. **個社設定ではどんな報告書の型を作るのか** → 電力会社の指定様式の写真台帳（工種・位置・確認項目・設計と実測）、官公庁の電子納品（デジタル写真管理情報基準に沿った写真と情報）、自社の施工管理アプリ・基幹システムへの出力。書式を整える工程は利用料に含み、有償は標準で足りない連携だけ。（p.15、見本の画像あり）

## 解決策
54. **照合（自動チェック）ができなくても意味があるのか** → ある。約2mのジョイントの組立図を壁に貼って往復している作業がなくなる。寸法の最終確認はスケールで、ARは「測る道具」ではなく「理解して間違いに気づく道具」。
55. **なぜ今、作業者向けのAIなのか** → 考える・書くAIは事務作業で実用の水準に来た。次は肉体労働の暗黙知を「見るAI」で支える番。カメラ付きAIグラスが普段のメガネの重さになり、表示付きのグラスも2025年に発売された。

## 社名・ロゴ・所在地
56. **社名とロゴの意味は** → 社名カンツギは「勘継」。割れた器を金で継ぐ金継ぎのように、途切れそうな現場の勘をデータで継ぐ。ロゴは、四隅のカギ括弧がスマートグラス（AR）のファインダー、立方体の三つの面が現場・現物・現実、側面を走る銅色の線が金継ぎの継ぎ目、銅色の上面の点がデータになった勘。銅色は電線の導体の色。
57. **会社の所在地は** → 川崎市を提案。羽田空港・新幹線に近く、関東一円の電気工事会社へ日帰りで出られる。オフィスは1年目15坪→5年目40坪。
