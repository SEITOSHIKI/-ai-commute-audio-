# 研修の事業計画を、10分・16枚・A4用紙2枚にまとめるまで

## 結論

## 具体的には
1. 設問①〜⑤の順に本編をつくる
2. 計算の過程は別冊の詳細版に分ける
3. 16枚に統合し、1ページ4枚で表裏2枚に印刷する
4. 台本を1分300字で計り、9分半に収める
5. AIっぽい言い回しとデザインを、自分の言葉と図面の書き方に直す

## 使える数字
- 本編33枚 → 16枚
- 台本 9分25秒
- A4用紙2枚（表裏4ページ・1ページ4枚）
