# 5年で黒字にならない計画を、そのまま出した理由

## 結論
黒字になる値を逆算して入れず、赤字のまま出して「何が変われば黒字になるか」を条件で示した。そのほうが質問に強い。

## 具体的には
1. 黒字になる値を逆算すると、どの前提を盛ったのか自分でも説明できなくなる
2. 黒字化の条件を1つに絞った：1拠点の台数を10台から15台に増やせれば、5年目に黒字になる
3. 5年で切らずに10年まで同じ式で延ばすと、利用料が積み上がる事業の姿が見える
4. 撤退ライン（進む・直す・止まる）を先に決めておくと、赤字でも続ける理由と止める理由がはっきりする

## 使える数字
- 5年目：81拠点・売上2.7億円・利益▲1,117万円・5年では黒字にならない
- 10年：黒字化6年目・累計の赤字の回収8年目・10年目の利益1.9億円

「融資のためによく見せたいのか」と問われて、計画を見直した場面を入れる。
