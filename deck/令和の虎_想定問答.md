## お金
4. **500万円で何ができるのか** → 6か月の準備期。3か月で試作品、6か月で1拠点の実証と有償試験導入3拠点の契約。給料はゼロ。
5. **500万円で足りないのでは** → 足りない。必要資金は1.5億円で、500万円は最初の一歩。実証の結果で公庫融資1,000万円、CVC・VCから1億1,500万円を調達する。
6. **黒字倒産しないのか** → 現金残高は3年目の谷でも6,000万円。最低残高を固定費3か月分（約2,000万円）に置き、利用料は年額前払い、導入支援は着手金50%。月次の資金繰り表で12か月先まで管理する。
7. **損益分岐点は** → 損益分岐点売上＝販管費÷粗利率。4年目は1億5,100万円に対し売上1億9,000万円で初めて超える。5年目の安全余裕率32%。人で見ると社員1人あたり2.8拠点。
8. **評価額4,500万円の根拠は** → 売上ゼロの段階の提案値。交渉の起点として、10%で500万円。【要決定】受け入れられる下限の比率を決めておく。
9. **虎はどう回収するのか** → 成熟期の上場、または事業会社（電設・建設テック・データ基盤）への売却。上場は目標で、時期は成長期の実績で判断する。

## 事業
10. **本当に顧客は払うのか** → 対象者100名の拠点で、日報などの書類作業が月6時間減ると年2,880万円分。年300万円は約1割で、約2.1か月で回収。ただし月6時間は建設業の書類電子化実績を準用した仮定で、実証で確かめる。
11. **ANDPADやSPIDERPLUSがあるのでは** → あれは人が撮って入力する器。当社は一人称で自動に記録し、写真を抜き出して報告書を作り、図面と照合し、熟練者の判断を教材にする。競わずにつなぐ（報告書と写真は各社の形式で出力）。最大の脅威は各社がAIで自動報告を加えることで、防御線は図面に現れない判断の蓄積と、施工経験者による監修。製造業のAirion・CADDiは対象が違う（補足資料）。
12. **常時録音・録画は現場が嫌がる** → 作業時間・作業エリアに限定し、本人同意と労使合意のもとで行う。休憩中・私語は自動除外。目的は監視ではなく、記録と報告の手間をなくすこと。
13. **スマートグラスの端末代は** → 顧客が市販品を購入する前提で、価格と回収期間の試算には含めていない。【要確認】台数と単価が決まれば試算に入れる。

## 追加の想定問答

14. **LTVはどう計算したのか** → 1拠点の年間粗利255万円（300万円×粗利率85%）を、保守的に7年分。そこに導入支援の粗利80万円（200万円×40%）を足して約1,865万円。計画上の年間解約率は約3.5%（5年目 3拠点÷85拠点）で、単純計算の継続年数はもっと長いが、実績がないため7年に抑えた。
15. **CACはどう計算したのか** → 5年目の営業人件費1,600万円（2名×800万円）と広告・展示会500万円の合計を、新規33拠点で割って約64万円。1〜2年目は創業者が営業するため人件費を入れていない。LTV/CACは約29倍だが、目安は3倍以上。実証で解約率と営業効率を確かめる。
16. **市場規模の根拠は** → 業種（電気工事・電気通信工事）×規模（大・中・小）で分け、顧客数×年額×年1回を足した。中堅以上の約3,100社で、ターゲット市場は約141億円（大手は支店5拠点分の1,500万円）。土台の65,497社は国の統計、規模別の内訳は推計。全体市場は建設テック（建築分野）2030年度約3,040億円・年7.4%など。自社が狙う市場は5年目85拠点×300万円＝2.55億円（約1.8%）。計算は `tora_market.js`、詳細は「市場規模_フェルミ推定.md」。
17. **チームは決まっているのか** → 【要記入】現時点で確定しているのは創業者1名。技術責任者・電気工事の施工管理経験者・顧問の状況（確定・内諾・打診中・募集中）を正直に答える。虎は「最重要」として必ず突く。
18. **家賃や広告費は** → 家賃は1年目月20万円・5年目月50万円、広告・展示会は1年目200万円・5年目500万円。その他経費（1年目1,200万円→5年目2,900万円）の内訳として置いた仮定。

## スマートグラス・ARの追加（2026年10月11日）

25. **スマートグラスは自社で開発するのか** → 作らない。作るのはアプリ・AI・データ基盤と、端末を壊さない保護カバー・ヘルメット取付具。端末は「落下2m級・IP66級・1シフトの電池・ヘルメット装着・手袋のまま音声操作」を満たす市販品を選び、世代が進めば乗り換える。今すぐは産業用ヘッドマウント端末（例：RealWear Navigator 520）とヘルメットカメラ、2〜3年目に法人向けAR端末でジョイント1種類を実証、2027年以降は一般向けARグラス（発売は報道ベース）。
26. **照合（自動チェック）ができなくても意味があるのか** → ある。約2mのジョイントの組立図を壁に貼って往復している作業がなくなる。実物大・立体・工程ごとの完成形を手元に出し、ベテランの注意点を該当箇所に固定表示できる。寸法の最終確認はスケールで、ARは「測る道具」ではなく「理解して間違いに気づく道具」。効果は手戻り件数・1ジョイントの作業時間・独り立ちまでの期間で測る。
27. **なぜ今、作業者向けのAIなのか** → 考える・書くAIは事務作業で実用の水準に来た。次は肉体労働の暗黙知を「見るAI」で支える番。表示付きスマートグラスは2025年に発売され、ARグラスも一般発売が報じられている。2024年からの残業上限と高齢化で、人を増やして解決できない。
28. **ミス事例はどう生かすのか** → 過去のミス事例を学習させ、ミスしやすい場面（赤を切るか青を切るか、の瞬間）を現物で認識したら、音声で警告し、レーザーポインターで正しい位置を示す。
