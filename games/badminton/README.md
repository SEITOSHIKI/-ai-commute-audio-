# ラリーIQ — バドミントン配球バトル

シングルスの配球判断を鍛えるブラウザゲーム。2つのモードがある。

- **ARENA（3D 対戦・メイン）** `arena/` — 自コートのベースライン後方からネット越しに見る3Dの対戦。相手コートにカーソルを当てて着地点（4隅・ハーフ・センターなど自由な位置）を決め、弾道の高さ（沈める／低く速く／ふつう／高く）とラケット面（カット量）を選んで「予約」すると、打点に入った瞬間にその打点から狙いを再現する角度と初速を逆算して打つ。シャトルは実物どおり空気抵抗で減速する（終端速度 6.8 m/s）。選手ごとに体格と6つの能力値があり、試合の経験値で育成できる。
- **配球ドリル（2D）** ルートの `index.html` — 相手コートの6ゾーンから狙いを即決するだけの判断練習。

## ARENA の仕組み

| ファイル | 役割 |
|---|---|
| `arena/physics.js` | シャトルの空気抵抗・スライス・ネットとライン判定、打点の高さと打てる角度／初速、CPU の配球選択（候補を全部物理で飛ばして相手の余裕が最小のものを選ぶ） |
| `arena/match.js` | 試合進行（サーブ、ラリー、得点、CPU とオートフットワークの移動、予約した配球を実際の打点に合わせ直す処理） |
| `arena/roster.js` | 選手名鑑（架空の6人）、能力値→物理パラメータの変換、経験値・レベル・能力ポイントの育成（端末内に保存） |
| `arena/game.js` | three.js での描画（関節つきの人体モデル、ショット別のスイング）、カーソルでの照準、選手選択と育成画面、HUD、効果音 |
| `arena/sim-arena.js` / `arena/sim-human.js` / `arena/sim-chars.js` | CPU 同士・人間役スクリプト・選手ごとの対戦成績のテスト（`node games/badminton/arena/sim-human.js`） |
| `arena/vendor/` | three.js 0.186.0（MIT。オフラインで動くよう同梱） |

ゲームの駆け引き:
- 予約が早すぎる（打点の0.35秒以上前）と CPU の反応が最大0.1秒速くなる。直前の予約とカットは逆に反応を遅らせる。
- 予約しないまま届くと「判断遅れ」で、質の落ちたロブを自動で上げる。
- 速い球ほど自分のホームへの戻りが遅れる（CPU の評価にも入っている）。

選手と能力値:

| 能力 | 試合への効き方 |
|---|---|
| パワー | スマッシュの最高初速（約 300〜360 km/h）とジャンプの高さ |
| スピード | フットワークの最高速度（約 4.5〜5.1 m/s）と加速 |
| 守備 | 速い球を受けたときの打点の質、横へのリーチ |
| コントロール | 狙いからのブレの小ささ |
| テクニック | カットの曲がりとスピンネットの回転、カットで相手の一歩目を遅らせる量 |
| 反応 | 相手が打ってから動き出すまでの時間 |

身長は最高到達点とリーチに、体格は最高初速と速さに、利き手はフォア／バックの側に効く。
実在の選手は名前・肖像の権利があるため収録していない（プレースタイルを参考にした架空の選手）。選手名は選択画面で書き換えられ、端末内にだけ保存される。

デバッグ用 URL: `?debug`（テスト用フック）、`?gallery`（人体モデルとスイングのポーズ一覧）。

ARENA を単体で開くときは HTTP サーバー経由で（ES モジュールのため `file://` では動かない）。

## 配球ドリル（2D）の遊び方

`index.html` をブラウザで開くだけ（ビルド不要・外部依存なし）。

家族への共有（Web 版・APK）と Google Play 公開の手順は [PUBLISHING.md](PUBLISHING.md) を参照。

```bash
# Docker で配信する場合の例（配布用ビルドを作ってから配信）
node games/badminton/scripts/build-web.mjs --out games/badminton/dist
docker run --rm -p 8080:80 -v "$PWD/games/badminton/dist:/usr/share/nginx/html:ro" nginx:alpine
# → http://localhost:8080
```

| 操作 | ゾーン |
|---|---|
| `Q` / `E`（テンキー `7` / `9`） | 左奥 / 右奥 |
| `A` / `D`（`4` / `6`） | 左中 / 右中 |
| `Z` / `C`（`1` / `3`） | 左前 / 右前 |

スマホはコートのゾーンをタップ。

## ルールの考え方

- **打点で打てるショットが変わる**: 高い打点 → クリアー/スマッシュ/ドロップ、ネット前で白帯より上 → ロブ/プッシュ/ヘアピン、低い打点 → ロブ/ハーフ/ヘアピン など。
- **相手の余裕 (margin)** = シャトルの飛行時間 −（反応 + 切り返し + 移動時間）。これが小さいほど相手の打点が下がり、マイナスならエース。
- 打った側はショット後にホームへ戻り始める。速い球を打つほど自分の戻りも遅れる。
- 相手の赤い矢印は戻っている方向。逆を突くと切り返しペナルティ（最大0.25秒）が乗る。
- 選択は変更不可。時間切れは「判断遅れ」で、体勢の崩れた甘いロブになる。
- 毎ショット、同じ評価関数で6択をランク付けし BEST / GOOD / OK / BAD を表示。試合後に「配球IQ」と弱点の打点を出す。

| 難易度 | 時間倍率 | CPU |
|---|---|---|
| 入門 | ×2.4 | ミス多め・選択がばらつく |
| 部活 | ×1.8 | |
| 実業団 | ×1.35 | |
| 代表 | ×1.05（ほぼ実時間） | ほぼ最善手 |

## ファイル

- `scripts/build-web.mjs` — 配布用 Web 一式を `dist/` に生成（`npm run build`。ルートが ARENA、`drill/` が 2D。フォント同梱・PWA 対応）
- `android/` — Capacitor の Android プロジェクト（`npm run android:sync` で `dist/` を反映）
- `privacy.html` — プライバシーポリシー（Play ストア申請用）
- `store/` — Play ストアの掲載文・アイコン・スクリーンショット
- `engine.js` — 配球シミュレーション（DOM 非依存。Node からも読める）
- `index.html` — 描画・入力・スコア
- `sim-test.js` — CPU 同士で数百試合回してバランスを確認: `node games/badminton/sim-test.js`（`diag` 引数でショット別 margin 分布）

パラメータ（移動速度、各ショットの飛行時間、ミス率）は `engine.js` 冒頭の `C` と `SHOTS` にまとまっているので、実際の感覚に合わせて調整してください。
