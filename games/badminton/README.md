# ラリーIQ — バドミントン配球バトル

シングルスの配球判断を鍛えるブラウザゲーム。相手が打った瞬間からシャトルが届くまでの間に、相手コートの6ゾーンから狙いを即決する。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要・外部依存なし）。

```bash
# Docker で配信する場合の例
docker run --rm -p 8080:80 -v "$PWD/games/badminton:/usr/share/nginx/html:ro" nginx:alpine
# → http://localhost:8080
```

| 操作 | ゾーン |
|---|---|
| `Q` / `E`（テンキー `7` / `9`） | 左奥 / 右奥 |
| `A` / `D`（`4` / `6`） | 左中 / 右中 |
| `Z` / `C`（`1` / `3`） | 左前 / 右前 |

スマホはコートのゾーンをタップ。

## ルールの考え方

- **打点で打てるショットが変わる**: 高い打点 → クリアー/スマッシュ/ドロップ、ネット前で白帯より上 → ロブ/プッシュ/ヘアピン、低い打点 → ロブ/ハーフ/ヘアピン など。
- **相手の余裕 (margin)** = シャトルの飛行時間 −（反応 + 切り返し + 移動時間）。これが小さいほど相手の打点が下がり、マイナスならエース。
- 打った側はショット後にホームへ戻り始める。速い球を打つほど自分の戻りも遅れる。
- 相手の赤い矢印は戻っている方向。逆を突くと切り返しペナルティ（最大0.25秒）が乗る。
- 選択は変更不可。時間切れは「判断遅れ」で、体勢の崩れた甘いロブになる。
- 毎ショット、同じ評価関数で6択をランク付けし BEST / GOOD / OK / BAD を表示。試合後に「配球IQ」と弱点の打点を出す。

| 難易度 | 時間倍率 | CPU |
|---|---|---|
| 入門 | ×2.4 | ミス多め・選択がばらつく |
| 部活 | ×1.8 | |
| 実業団 | ×1.35 | |
| 代表 | ×1.05（ほぼ実時間） | ほぼ最善手 |

## ファイル

- `engine.js` — 配球シミュレーション（DOM 非依存。Node からも読める）
- `index.html` — 描画・入力・スコア
- `sim-test.js` — CPU 同士で数百試合回してバランスを確認: `node games/badminton/sim-test.js`（`diag` 引数でショット別 margin 分布）

パラメータ（移動速度、各ショットの飛行時間、ミス率）は `engine.js` 冒頭の `C` と `SHOTS` にまとまっているので、実際の感覚に合わせて調整してください。
