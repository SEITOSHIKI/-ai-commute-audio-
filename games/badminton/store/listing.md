ラリーIQ - バドミントン配球バトル

## 簡単な説明（80文字以内）

```
コースと弾道を即決。個性ある選手を育てる、本物の弾道の3Dバドミントン対戦。
```

## 詳しい説明（4000文字以内）

```
相手コートのどこへ、どの高さで、どんな面で。シャトルが届く前に決めて打つ、本物の空気抵抗で飛ぶ3Dバドミントン対戦。

■ 本物の弾道
シャトルは実物と同じように空気抵抗で急減速します。300km/hを超えるスマッシュも、奥からでは角度を付けすぎるとネットにかかる。クリアーは奥でストンと落ちる。打点の高さで打てる角度と速さが変わります。

■ ネット越しに狙う
自コートの後ろからネット越しに相手を見る視点。相手コートの4隅・ハーフ・センターなど、カーソル（指）を当てた場所がそのまま狙いになります。
・弾道の高さ：沈める／低く速く／ふつう／高く。打点が低ければ沈められない
・ラケット面：カットやリバースカット。球が遅く短くなり、横に曲がり、相手の一歩目を遅らせる

■ 個性のある選手と育成
レフティのオールラウンダー、手首で騙すトリックスター、長身の剛腕スマッシャー、粘りのディフェンダーなど6人。身長・利き手・パワー・スピード・守備・コントロール・テクニック・反応がそれぞれ違い、スマッシュの速さや届く範囲が変わります。試合で経験値を積んでレベルを上げ、能力ポイントを自分で振って育てられます。

■ ショットごとのフォーム
スマッシュ、クリアー、カット、ドライブ、プッシュ、ネット前のランジ、ロブ、サーブ。打つ球と打点に合わせて、腕と体のフォームが変わります。

■ 決めるタイミングが勝負
配球は打つ前に「予約」します。早く決めすぎると相手に読まれ、決められないまま届くと体勢の崩れた甘いロブになる。届く直前まで溜めて、逆を突け。

■ 毎ショットを採点
初速・角度と「相手の余裕（秒）」を表示。相手が届かないエース級か、高い打点で打ち返される甘い球かがすぐ分かります。試合後には最速スマッシュ、平均判断時間、傾向に応じたアドバイス。

■ 遊び方を選べる
・難易度4段階（入門／部活／実業団／代表）。上ほど実時間に近く、弾道ガイドが短くなる
・フットワーク：オート（配球の判断に集中）／マニュアル（移動も自分で）
・選手名は自由に書き換え可能
・2D配球ドリル：6つのゾーンから選ぶだけの判断トレーニングも収録

広告なし・アカウント登録なし・個人情報の収集なし。オフラインで遊べます。
```
